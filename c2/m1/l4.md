Lesson 4 — How LLMs Are Trained
Core idea: An LLM starts as a statistical text predictor and is progressively trained into an instruction-following, aligned assistant.    Pasted markdown
1. The Big Picture
The training pipeline has three major stages:
Pre-training → Supervised Fine-Tuning → RLHF
Stage	Main purpose	What the model learns
1. Pre-training	Learn language	Patterns, grammar, facts, broad knowledge
2. SFT	Learn instructions	How to answer and behave like an assistant
3. RLHF	Learn preferences	Helpfulness, safety, preferred behavior


This explains why a raw model behaves very differently from ChatGPT-like assistants.    Pasted markdown
2. Transformer + Attention
The Transformer is the architecture underlying modern LLMs.
Its key innovation is self-attention: each token can determine which other tokens are important to understanding the current context.
For example:
"The animal didn't cross the street because it was tired."

Attention helps the model connect "it" → "animal".
Conceptually:
Query (Q) → What am I looking for?
Key (K) → What information do I contain?
Value (V) → What information should I provide?
The attention calculation is:
Attention(Q,K,V) = softmax(QKᵀ / √d)V
Transformers were a major improvement over RNNs/LSTMs because they allow parallel processing and better handling of long-range relationships.    Pasted markdown
3. Pre-training
This is where the model develops its general language ability.
The model is exposed to enormous amounts of text and repeatedly performs:
Predict the next token.

Example:
"The capital of Italy is ___"

Model predicts:
Rome

If the prediction is wrong, the model calculates loss, uses backpropagation/gradient descent, and adjusts its parameters.
This happens billions of times.
Important insight
Pre-training does not directly teach:
"Answer questions."

It teaches:
"Predict what text is statistically likely to come next."

The result is a base model.
A base model can have enormous knowledge but may not behave like an assistant.    Pasted markdown
4. Why Does a Base Model Hallucinate?
This lesson makes an important connection:
Training objective = statistical prediction, not truth verification.
The model learns patterns in its training data.
Therefore:
Likely continuation ≠ necessarily factual continuation

This is one reason hallucinations occur.
The model may generate an answer that sounds extremely plausible even when it is false.    Pasted markdown
5. Supervised Fine-Tuning — SFT
Now we take the base model and teach it how to behave as an assistant.
Training data looks like:
Instruction:
Explain the water cycle simply.

Response:
The water cycle is the continuous movement
of water through evaporation, condensation...

Thousands or millions of high-quality examples teach the model patterns such as:
- Answer directly
- Follow instructions
- Use appropriate formatting
- Ask clarifying questions
- Adopt a particular style
Key distinction
Pre-training → broad knowledge and language ability
SFT → behavior and instruction-following
SFT is much cheaper than pre-training.
Techniques such as LoRA/QLoRA can make fine-tuning considerably more efficient.    Pasted markdown
6. RLHF — Reinforcement Learning from Human Feedback
SFT teaches:
"How should I answer?"

RLHF tries to teach:
"Which answers do humans prefer?"

Typical process:
LLM generates multiple answers
          ↓
Humans rank the answers
          ↓
Reward Model learns those preferences
          ↓
LLM is optimized to get higher reward

So RLHF helps improve:
- Helpfulness
- Safety
- Honesty
- Conciseness
- Preferred communication style
The lesson describes the LLM as the policy and the separate model that predicts human preferences as the reward model.    Pasted markdown
7. RLHF Has Problems Too
RLHF does not make a model perfect.
Important failure modes include:
- Reward hacking — finding ways to maximize the reward without genuinely achieving the intended goal
- Goodhart's Law — optimizing a proxy can produce undesirable behavior
- Sycophancy — agreeing with users too readily
- Expensive human feedback
- Subjective values — different people may prefer different behavior
The lesson also introduces alternatives such as DPO, RLAIF and Constitutional AI.    Pasted markdown
8. Base Model vs Instruction-Tuned Model
This is probably the most practically important concept for prompt engineering.
Base model
Think:
"Complete this text."

Instruction-tuned model
Think:
"Understand the user's request and perform it."

For example:
Prompt:
Explain the water cycle.

A base model might continue the sentence or produce an essay-like continuation.
An instruction-tuned model directly explains the water cycle.
So the same underlying model knowledge can produce very different behavior depending on training.    Pasted markdown
9. The Most Important Mental Model
Think of an LLM like a person:
📚 Pre-training
"Read the entire library."
The person gains broad knowledge and language ability.
👨‍🏫 SFT
"Learn how to answer questions properly."
The person learns expected behavior.
👥 RLHF
"Now learn what people consider a good answer."
The person gets feedback and adjusts behavior.
This analogy is one of the lesson's central teaching devices.
10. What the Mathematics Is Saying
The fundamental objective is:
\[
P(w_1,w_2,...,w_T)
=
\prod_t P(w_t|w_1,...,w_{t-1})
\]
In simple terms:
The probability of a complete sentence comes from predicting each token based on the tokens before it.

Training minimizes:
\[
Loss=-\frac{1}{T}\sum_t\log P(w_t|w_1,...,w_{t-1})
\]
If the model gives the correct token a higher probability, loss decreases.
So at its foundation:
LLM training = repeatedly adjusting billions of parameters to improve next-token prediction.    Pasted markdown
11. Why This Matters for Prompt Engineering
This lesson is ultimately preparing you for prompt engineering.
Your prompt is not interacting with a blank intelligence.
It is interacting with a model that has already gone through a particular training history.
Therefore:
Prompt → model's learned representations + training behavior → response
Understanding training helps explain:
- Why prompting works
- Why few-shot examples work
- Why instruction-tuned models are easier to prompt
- Why models hallucinate
- Why models refuse certain requests
- Why fine-tuning isn't always the best solution
- Why RAG can be preferable for factual/domain knowledge
The lesson explicitly connects training knowledge to decisions between prompting, fine-tuning and RAG.    Pasted markdown

One-line summary:
Pre-training gives an LLM its broad capabilities, SFT teaches it how to follow instructions, and RLHF shapes how it behaves according to human preferences.    Pasted markdown

⭐ The most important distinction
Knowledge ≠ behavior.
A model can already know something during pre-training but still need fine-tuning to learn how to respond when asked about it. That distinction is fundamental to understanding modern LLMs.
